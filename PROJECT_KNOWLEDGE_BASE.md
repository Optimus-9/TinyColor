## 3. ORIGINAL JAVASCRIPT TECHNICAL SPECIFICATION

### 3.1 Class & Object State (`tinycolor`)
The JS implementation wraps color state into an object with the following internal properties:
* `_originalInput`: Exact raw argument passed into `tinycolor(input)` (String, Object, or `tinycolor` instance).
* `_r`, `_g`, `_b`: Floating-point red, green, and blue values normalized in the `[0, 255]` range.
* `_a`: Floating-point alpha value normalized in the `[0.0, 1.0]` range.
* `_roundA`: Cached rounded alpha `Math.round(100 * _a) / 100` for output string generation.
* `_format`: Detected string/object format (e.g., `"hex"`, `"hex3"`, `"hex4"`, `"hex6"`, `"hex8"`, `"rgb"`, `"prgb"`, `"hsl"`, `"hsv"`, `"name"`).
* `_gradientType`: Optional flag for IE filter generation (`"GradientType = 1, "` if set).
* `_ok`: Boolean flag indicating whether input parsing succeeded (`true` if valid color, `false` otherwise).

*Special Invariant:* If `_ok === false`, operations fallback to behaving like black (`rgb(0,0,0)`).

### 3.2 Parsing Pipeline (`inputToRGB` & `stringInputToObject`)

#### 1. Input Types Handled
* **Instance Copying:** Passing an existing `tinycolor` object returns the exact same instance.
* **String Inputs:** Parsed via regular expressions and named color dictionaries.
* **Object Inputs:**
  * RGB: `{ r: 255, g: 0, b: 0, a: 1 }` or percentages `{ r: "100%", g: "0%", b: "0%" }`.
  * HSL: `{ h: 360, s: 100, l: 50 }` or ratio `{ h: 1, s: 1, l: 0.5 }`.
  * HSV: `{ h: 360, s: 100, v: 100 }` or ratio `{ h: 1, s: 1, v: 1 }`.
* **Ratios (`tinycolor.fromRatio`):** Accepts `0.0 - 1.0` range for RGB and Hue components.

#### 2. Permissive String Matchers (Regex Specifications)
```javascript
CSS_INTEGER = "[-\\+]?\\d+%?"
CSS_NUMBER = "[-\\+]?\\d*\\.\\d+%?"
CSS_UNIT = "(?:" + CSS_NUMBER + ")|(?:" + CSS_INTEGER + ")"
PERMISSIVE_MATCH3 = "[\\s|\\(]+(" + CSS_UNIT + ")[,|\\s]+(" + CSS_UNIT + ")[,|\\s]+(" + CSS_UNIT + ")\\s*\\)?"
PERMISSIVE_MATCH4 = "[\\s|\\(]+(" + CSS_UNIT + ")[,|\\s]+(" + CSS_UNIT + ")[,|\\s]+(" + CSS_UNIT + ")[,|\\s]+(" + CSS_UNIT + ")\\s*\\)?"
```
* **HEX Formats:**
  * `hex3`: `#f00` / `f00`
  * `hex6`: `#ff0000` / `ff0000`
  * `hex4`: `#f00f` / `f00f` (RGBA)
  * `hex8`: `#ff0000ff` / `ff0000ff` (RGBA)
* **Named Colors:** 148 W3C CSS named colors mapped bidirectionally (`names` dictionary and inverse `hexNames`). Special keyword `"transparent"` returns `{ r:0, g:0, b:0, a:0, format:"name" }`.

### 3.3 Color Space Transformations & Algorithms

#### RGB ↔ HSL Conversion
```javascript
// RGB [0, 255] -> HSL [h: 0..360, s: 0..1, l: 0..1]
function rgbToHsl(r, g, b) {
  r = bound01(r, 255); g = bound01(g, 255); b = bound01(b, 255);
  max = Math.max(r, g, b); min = Math.min(r, g, b);
  l = (max + min) / 2;
  if (max === min) { h = s = 0; } // achromatic
  else {
    d = max - min;
    s = l > 0.5 ? d / (2 - max - min) : d / (max + min);
    switch(max) {
      case r: h = (g - b) / d + (g < b ? 6 : 0); break;
      case g: h = (b - r) / d + 2; break;
      case b: h = (r - g) / d + 4; break;
    }
    h /= 6;
  }
  return { h: h * 360, s: s, l: l };
}
```

#### RGB ↔ HSV Conversion
```javascript
// RGB [0, 255] -> HSV [h: 0..360, s: 0..1, v: 0..1]
function rgbToHsv(r, g, b) {
  r = bound01(r, 255); g = bound01(g, 255); b = bound01(b, 255);
  max = Math.max(r, g, b); min = Math.min(r, g, b);
  v = max; d = max - min;
  s = max === 0 ? 0 : d / max;
  if (max === min) { h = 0; }
  else {
    switch(max) {
      case r: h = (g - b) / d + (g < b ? 6 : 0); break;
      case g: h = (b - r) / d + 2; break;
      case b: h = (r - g) / d + 4; break;
    }
    h /= 6;
  }
  return { h: h * 360, s: s, v: v };
}
```

### 3.4 Color Modifications & Combinations

| Method | Algorithm Summary |
| :--- | :--- |
| `lighten(amount)` | Increases HSL Lightness `l += amount / 100`, clamped `[0, 1]`. Default `amount = 10`. |
| `darken(amount)` | Decreases HSL Lightness `l -= amount / 100`, clamped `[0, 1]`. Default `amount = 10`. |
| `brighten(amount)`| Modifies RGB channel values `rgb = Math.max(0, Math.min(255, rgb - Math.round(255 * -(amount/100))))`. |
| `saturate(amount)`| Increases HSL Saturation `s += amount / 100`, clamped `[0, 1]`. |
| `desaturate(amount)`| Decreases HSL Saturation `s -= amount / 100`, clamped `[0, 1]`. |
| `greyscale()` | Equivalent to `desaturate(100)`. |
| `spin(amount)` | Adjusts Hue `(hsl.h + amount) % 360`. Wraps negative angles (`+360`). |
| `complement()` | Rotates Hue by 180° `(hsl.h + 180) % 360`. |
| `triad()` | Generates 3 colors spaced by 120° (`polyad(3)`). |
| `tetrad()` | Generates 4 colors spaced by 90° (`polyad(4)`). |
| `splitcomplement()`| Returns base color, `+72°`, and `+216°` hue shifts. |
| `analogous(results, slices)`| Returns `results` colors stepping by `360 / slices`. Default: `results = 6, slices = 30`. |
| `monochromatic(results)`| Stepwise HSV Value decrement `v = (v + (1/results)) % 1`. |

### 3.5 Accessibility & WCAG 2.0 Readability Math

* **Perceived Brightness (AERT standard):**
  $$\text{Brightness} = \frac{(R \times 299) + (G \times 587) + (B \times 114)}{1000}$$
  * Light if $\text{Brightness} \ge 128$, Dark if $< 128$.

* **Relative Luminance (WCAG 2.0):**
  $$\text{Luminance} = 0.2126 \times R_{\text{linear}} + 0.7152 \times G_{\text{linear}} + 0.0722 \times B_{\text{linear}}$$
  where for $C \in \{R, G, B\} / 255$:
  $$C_{\text{linear}} = \begin{cases} \frac{C}{12.92} & \text{if } C \le 0.03928 \\ \left(\frac{C + 0.055}{1.055}\right)^{2.4} & \text{otherwise} \end{cases}$$

* **Contrast Ratio:**
  $$\text{Contrast} = \frac{\max(L_1, L_2) + 0.05}{\min(L_1, L_2) + 0.05}$$

* **WCAG Compliance Thresholds (`isReadable`):**
  * `AA / small`: Contrast $\ge 4.5$
  * `AA / large`: Contrast $\ge 3.0$
  * `AAA / small`: Contrast $\ge 7.0$
  * `AAA / large`: Contrast $\ge 4.5$

### 5.2 Critical Edge Cases & Precision Pitfalls
1. **Decimal "1.0" Handling (`isOnePointZero`):**
   In JS, string `"1.0"` must be treated as `100%`, whereas integer `1` or string `"1"` is treated as absolute value `1/255`. In Go, type assertions must distinguish string inputs carefully before float conversion.
2. **Alpha Rounding (`roundA`):**
   JS calculates `Math.round(100 * a) / 100`. Go string format formatting must preserve trailing decimals when required (`0.5` vs `.5`).
3. **Invalid Color Fallback:**
   Invalid inputs must return a `Color` object with `ok = false`. Calling `.ToHexString()` on an invalid color must return `"#000000"`, behaving exactly like black while maintaining `ok = false`.
4. **Hex Alpha Formatting:**
   `toHex8()` uses ARGB in `toFilter()`, but standard Hex8 is RGBA. Strict differentiation between `rgbaToHex` and `rgbaToArgbHex` is required.
